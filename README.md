# Aria's World

A coloring, drawing, tracing and matching game for young children. Play it at
**https://atrido.github.io/Aria-s-World---Web-Game-/** (works offline and can be added to the Home Screen).

```sh
npm install
npm run dev     # local game at http://localhost:5173/
npm run build   # typecheck + build into dist/
```

Pushing to `main` publishes the game automatically (GitHub Actions → GitHub Pages).
