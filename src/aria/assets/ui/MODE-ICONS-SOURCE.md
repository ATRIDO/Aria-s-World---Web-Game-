# Main-menu mode icons (`mode-*.webp`)

Made on 2026-10-09 with Higgsfield (Nano Banana 2, owner's account, unlimited generations, 0 credits),
from text prompts only: no reference images, no third-party characters or brands. Original art for
Aria's World. Each was generated as a 1024 px square, then resized to 512 px and saved as WebP
(white corners made transparent) with a small Pillow script.

Subjects: color (crayon box), sketch (pencil cup), trace (A and 1), match (shape board),
dress up (original doll and clothes rack), tug of war (two cartoon kids and a rope), memory (cards).

Prompt pattern: "Square app game-button icon artwork for a toddler game, fills the whole square edge to
edge, no border, no text, no letters. Cute flat vector illustration with thick warm dark-brown
outlines, soft gradients, glossy highlights, bright cheerful colors. Subject: ... on a <color>
background with tiny white sparkles. Original design, friendly and simple, large shapes easy to recognize."
